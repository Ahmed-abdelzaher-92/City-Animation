# مشروع الرسوميات: مشهد مدينة متحرك (Computer Graphics Animation)

مشهد مدينة كامل بيتحرك (عربية ماشية على طريق متموج، عجلات بتلف، شمس أشعتها بتدور،
سحاب بيتحرك، عصافير بتخفق)، مكتوب بـ Python باستخدام Matplotlib و NumPy بس.

أهم نقطة في المشروع: مفيش ولا شكل جاهز من المكتبات. كل اللي على الشاشة بيترسم
بيكسل بيكسل عن طريق خوارزميات الرسم اللي اتدرست في السكاشن، مكتوبة من الصفر
في ملف `algorithms.py`.

## الخوارزميات المستخدمة ومكانها في المشهد

| الخوارزمية | الدالة | بتترسم فين في المشهد |
|---|---|---|
| رسم خط DDA | `dda_line` | أجنحة العصافير، سيقان الورد، خطوط الطريق المتقطعة، حرفة الطريق |
| رسم خط Bresenham | `bresenham_line` | أشعة الشمس، أذرع العجلات اللي بتلف، عمود الإنارة |
| دايرة نقطة المنتصف | `midpoint_circle` | الشمس، العجلات، الورد، لمبة عمود الإنارة |
| إهليج نقطة المنتصف | `midpoint_ellipse` | السحاب (كل سحابة 3 إهليجات مليانة) |
| منحنى Bezier | `bezier_curve` | شكل الطريق المتموج كله (المنحنى هو العمود الفقري للمشهد) |
| تلوين Scanline | `scanline_fill` | جسم الطريق بين منحنيين، كابينة العربية (شبه المنحرف) |

الحركة نفسها مبنية على الخوارزميات: العربية بتمشي على نقاط منحنى Bezier محسوبة
بالمسافة الفعلية على المنحنى، وزاوية لف العجلات = المسافة المقطوعة ÷ نصف قطر العجلة،
فالعجلة بتلف بالظبط زي عجلة حقيقية بتلمس الأرض.

## المتطلبات

- Python 3.10 أو أحدث
- المكتبات في `requirements.txt` (NumPy و Matplotlib، ومعاهم Pillow بيجي عادة مع Matplotlib)
- برنامج ffmpeg (اختياري): مطلوب بس لو عايز تصدّر الفيديو MP4. العرض اللايف
  وحفظ الـGIF مش محتاجينه.

## التشغيل

عرض لايف (مناسب للمناقشة، مش محتاج ffmpeg):

```bash
pip install -r requirements.txt
python live.py
```

تصدير فيديو MP4 (محتاج ffmpeg):

```bash
python animation.py
```

الناتج بيتكتب في `output/city_animation.mp4` (10 ثواني، 24 إطار في الثانية، 1280x720).

اختيارات إضافية:

```bash
python live.py --seconds 15              # لفة أطول في العرض اللايف
python live.py --save-gif output/city.gif  # حفظ GIF بدل فتح نافذة (مش محتاج ffmpeg)
python animation.py --seconds 15 --fps 30  # فيديو أطول وأنعم
python animation.py --keep-frames          # سيب صور الإطارات PNG بعد التصدير
python preview.py                          # معاينة سريعة: 4 لقطات ثابتة في output/
```

## شرح مختصر لكل خوارزمية

- DDA: بنحسب أكبر فرق بين Δx و Δy ونقسم عليه، ونزود الإحداثيات بخطوات صغيرة
  ونقرّب لأقرب بيكسل. بسيطة لكن بتستخدم كسور.
- Bresenham: نفس الهدف لكن بأرقام صحيحة بس ومتغير خطأ (error term) بيقرر
  نتحرك قطري ولا أفقي. أسرع وأدق على الشاشة.
- دايرة نقطة المنتصف: بنرسم ثُمن الدايرة بس ونكمل الباقي بالتناظر في 8 اتجاهات،
  وقرار كل خطوة مبني على إشارة دالة الدايرة عند نقطة المنتصف بين بيكسلين.
- إهليج نقطة المنتصف: نفس فكرة الدايرة لكن بمنطقتين، لأن ميل الإهليج بيتغير
  من أقل من 1 لأكبر من 1.
- Bezier: منحنى ناعم بيتحكم فيه نقاط تحكم، بنحسبه بمعادلة Bernstein.
  الطريق في المشهد منحنى تكعيبي (4 نقاط تحكم).
- Scanline Fill: بنمشي سطر سطر، نلاقي نقاط تقاطع السطر مع أضلاع المضلع،
  نرتبها ونلوّن بين كل زوج (قاعدة even-odd).

## ملاحظة مهمة للمناقشة

أسماء الخوارزميات المكتوبة هنا هي الأسماء الكلاسيكية المتعارف عليها (DDA، Bresenham،
Midpoint، Bezier، Scanline Fill). قارنها بنفسك مع اللي اتدرس فعلًا في السكاشن:
لو خوارزمية منهم متدرستش عندكم، الأفضل تستبدلها أو تستبعد الجزء اللي بيستخدمها
من المشهد، ولو الخوارزمية اتدرست باسم أو اصطلاح مختلف اذكر المقابل في التقرير.
متفترضش إن الأسماء هنا هي نفسها اللي اتقالت في المحاضرة.
